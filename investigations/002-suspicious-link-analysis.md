# Investigation 002 — Suspicious Link Analysis

**Status:** 🟡 Planned  
**Scenario type:** Simulated / Benign Training Sample

## Objective

Analyze a simulated suspicious URL from a SOC perspective using safe, non-interactive methods. The investigation will focus on URL structure, domain context, DNS observations, IOC extraction, and analyst risk assessment.

## Planned Analysis

- Parse the URL structure
- Review scheme, hostname, path, query parameters, and encoded content
- Identify misleading or lookalike domain patterns
- Review domain/DNS context using safe methods
- Document redirects only when using benign training infrastructure
- Extract sanitized IOCs
- Assess likely user impact and required response
- Map supported behavior to MITRE ATT&CK where appropriate
